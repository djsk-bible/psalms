# 시편 읽기표 V29

시편 150편 읽기 체크 앱입니다. (성경 본문은 없고, 읽은 편만 체크합니다)

## 깃허브에 올리는 방법
1. 저장소에서 **Add file → Upload files**
2. 이 폴더의 파일을 **모두** 끌어다 놓고 **Commit changes** (같은 이름은 새 파일로 바뀌어요)
3. 1~2분 뒤 반영돼요. 앱 주소: `https://djsk-bible.github.io/psalms/`

## 파일 설명
- `index.html` — 앱 본체
- `version.json` — 새 버전 확인용 (앱이 이 번호를 보고 "새 버전이 있어요"를 띄워요)
- `manifest.webmanifest` — 앱 이름·아이콘 정보 (설치용)
- `sw.js` — 인터넷이 없어도 열리게 하는 파일
- `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` — 아이콘

## 고칠 때
- 세 곳의 번호를 **같이** 올려요: `index.html`의 `APP_VER`, `version.json`의 `v`, `sw.js`의 `CACHE`
- 올린 뒤 앱을 열면 위쪽에 "새 버전이 있어요 [바꾸기]"가 떠요. 누르면 기록은 그대로 두고 새 버전으로 바뀌어요.
- V19 이하가 깔린 기기는 [바꾸기] 띠가 안 뜰 수 있어요. 앱을 완전히 닫았다 두세 번 다시 열면 바뀌어요.

## 주의
- 기록은 각자 휴대폰(그 브라우저)에만 저장돼요. 다른 기기로 옮길 때는 설정 → 기록 내보내기/불러오기.
- 인터넷 기록을 지울 때 **사이트 데이터**까지 지우면 기록이 사라져요.
- 저장소 이름(psalms)과 주소를 바꾸지 마세요. 바꾸면 기존 기록이 안 보여요.
- 홈 화면 아이콘이 바뀌는 데는 하루 이상 걸릴 수 있어요. 앱을 지웠다 다시 깔지 마세요.
